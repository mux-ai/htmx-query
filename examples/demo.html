SWR cache

hx-swr="15" caches this list for 15 seconds. The server waits 800 ms, so repeat clicks should feel instant.

      Drag to reorder

      Drag a task on desktop, or use its Move up/down buttons. The row moves immediately; the ordered IDs are then posted to the server. A successful mutation invalidates and re-fetches this cached list.

      Native drag + cache

        How to verify: click a task’s ↑ or ↓ button and watch its position change; then open peek() to see the task cache refill after the POST. Native desktop drag now sets a browser data payload, but production touch interactions may still benefit from an accessible drag-and-drop library. Reorder POSTs are deliberately not retried by default.

const taskRows = () => [...taskList.querySelectorAll('[data-task-id]')];
const currentOrder = () => taskRows().map((row) => row.dataset.taskId);
const persistOrder = () => {
  orderInput.value = currentOrder().join(',');
  htmx.trigger(reorderForm, 'submit');
};

taskList.addEventListener('dragstart', (event) => {
  draggedTask = event.target.closest('[data-task-id]');
  if (!draggedTask) return;
  priorOrder = currentOrder();
  draggedTask.classList.add('dragging');
  if (event.dataTransfer) {
    event.dataTransfer.setData('text/plain', draggedTask.dataset.taskId);
    event.dataTransfer.effectAllowed = 'move';
  }
});

taskList.addEventListener('click', (event) => {
  const button = event.target.closest('[data-move]');
  if (!button) return;
  // Move the selected row up or down, then persistOrder().
});

const afterRequestEvent = Number.parseInt(htmx.version, 10) >= 4 ? 'htmx:after:request' : 'htmx:afterRequest';
document.addEventListener(afterRequestEvent, (event) => {
  if (event.target !== reorderForm) return;
  const successful = event.detail.ctx ? event.detail.ctx.response.status < 400 : event.detail.successful;
  if (successful) htmx.query.invalidate('/tasks');
  else restoreOrder();
});
